# 🚀 Инструкция по настройке сайта Clean73

## Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

Сайт откроется по адресу: http://localhost:5173

### 3. Сборка для продакшена

```bash
npm run build
```

Готовые файлы будут в папке `dist/`

---

## ⚙️ Обязательная настройка контактов

### 📱 Telegram

Замените `himclean_pro` на ваш username в Telegram:

1. **В файле `src/main.js`** (строка 23):
```javascript
const telegramUsername = 'ваш_username';
```

2. **В файле `index.html`**:
   - Найдите все упоминания `@himclean_pro` или `himclean_pro`
   - Замените на ваш username

3. **В файле `privacy.html`**:
   - Найдите все упоминания `@himclean_pro`
   - Замените на ваш username

### 📞 Телефон

Замените `+79962197721` на ваш реальный номер:
- В `index.html` (несколько мест в шапке и футере)
- В `privacy.html`

### 🏢 Юридическая информация

В файлах `index.html` и `privacy.html` найдите и замените:
- **ИП Иванов И.И.** → ваше наименование
- **ИНН: 1234567890** → ваш ИНН
- **г. Ульяновsk** → ваш город

## 📊 Настройка Яндекс.Метрики

1. Создайте счетчик на [metrika.yandex.ru](https://metrika.yandex.ru)
2. Скопируйте ID счетчика
3. В файле `index.html` найдите все упоминания `XXXXXXXXX` и замените на ваш ID:

```javascript
ym(ваш_ID, "init", {
```

и

```html
<img src="https://mc.yandex.ru/watch/ваш_ID" ...
```

## 🖼️ Добавление изображений

### Необходимые изображения:

Добавьте в папку `public/images/`:

1. **hero-cleaning.jpg** - главное изображение
   - Рекомендуемый размер: 800x600px
   - Фото "до/после" или процесс уборки

2. **work-1.jpg до work-6.jpg** - примеры работ
   - Рекомендуемый размер: 600x400px
   - Фотографии ваших выполненных работ

### Оптимизация изображений:

Используйте сервисы для сжатия:
- [TinyPNG](https://tinypng.com/)
- [Squoosh](https://squoosh.app/)

Целевой размер файла: не более 200-300 KB на изображение.

## 🎨 Изменение цветов (опционально)

Цвета настраиваются в файле `tailwind.config.js`:

```javascript
colors: {
  'alice-blue': '#F0F8FF',    // Фон
  'sky-blue': '#87CEFA',       // Основной голубой
  'dark-slate': '#2c3e50',     // Текст
  'accent-orange': '#FFA500',  // Кнопки
  'light-gray': '#EAECEE',     // Разделители
}
```

## 📝 Редактирование контента

### Изменение услуг

В `index.html` найдите секцию `<!-- Services Section -->` и отредактируйте блоки с услугами.

### Изменение преимуществ

В `index.html` найдите секцию `<!-- Advantages Section -->` и отредактируйте преимущества.

### Изменение отзывов

В `index.html` найдите секцию `<!-- Reviews Section -->` и замените на реальные отзывы ваших клиентов.

## 🌐 Публикация сайта

### Вариант 1: Vercel (рекомендуется)

1. Зарегистрируйтесь на [vercel.com](https://vercel.com)
2. Подключите репозиторий
3. Vercel автоматически определит настройки
4. Сайт будет опубликован автоматически

### Вариант 2: Netlify

1. Зарегистрируйтесь на [netlify.com](https://netlify.com)
2. Подключите репозиторий
3. Build command: `npm run build`
4. Publish directory: `dist`

### Вариант 3: Обычный хостинг

1. Выполните `npm run build`
2. Загрузите содержимое папки `dist/` на хостинг
3. Настройте домен на папку с файлами

## 🔧 Дополнительно

### Настройка домена

После публикации настройте домен `himclean.pro`:
1. Добавьте A-запись или CNAME у вашего регистратора
2. Укажите на сервер хостинга
3. Дождитесь обновления DNS (до 48 часов)

### Настройка целей в Яндекс.Метрике

После добавления счетчика создайте цель:
- Тип: JavaScript-событие
- Идентификатор: `telegram_click`
- Название: "Клик по Telegram"
