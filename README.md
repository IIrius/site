# Clean73 - Сайт клининговой компании

Профессиональная уборка и химчистка в Ульяновске.

## 🚀 Технологический стек

- **Vite** - быстрая сборка и dev-сервер
- **Tailwind CSS** - utility-first CSS фреймворк
- **Vanilla JavaScript** - без тяжелых фреймворков
- **HTML5** - семантическая разметка

## 📦 Установка и запуск

### Установка зависимостей

```bash
npm install
```

### Режим разработки

```bash
npm run dev
```

Сайт будет доступен по адресу: http://localhost:5173

### Сборка для продакшена

```bash
npm run build
```

Готовые файлы будут в папке `dist/`

### Предпросмотр продакшн-версии

```bash
npm run preview
```

## 🎨 Цветовая схема

- **Основной фон**: `#F0F8FF` (Alice Blue) - светлый голубой
- **Основной голубой**: `#87CEFA` (Light Sky Blue) - для заголовков и иконок
- **Текст**: `#2c3e50` (Dark Slate Blue) - темный, но не черный
- **Акцент/CTA**: `#FFA500` (Orange) - яркий оранжевый для кнопок
- **Нейтральный**: `#EAECEE` (Светло-серый) - для разделителей

## 🌐 Деплой

Сайт можно развернуть на любом хостинге:

- **Vercel**: `vercel --prod`
- **Netlify**: подключите репозиторий и настройте build command `npm run build`
- **GitHub Pages**: используйте GitHub Actions для автоматического деплоя
- **Обычный хостинг**: загрузите содержимое папки `dist/` после сборки
